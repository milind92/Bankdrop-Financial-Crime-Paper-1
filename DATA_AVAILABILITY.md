# Data Availability

## Public Repository

This repository contains deterministic Phase 1–4 code, documentation, privacy-safe aggregate and derived-analysis outputs, and aggregate human inter-coder reliability and adjudication results. It does not contain a manuscript or submission package.

## Controlled Material

The underlying corpus is not publicly available. Excluded material includes raw Markdown notes, screenshots, OCR text, direct excerpts, source identifiers, URLs, handles, payment or account-like identifiers, evidence packets, coder workbooks, rationales, record-level decisions, adjudication rows, signatures, record- or evidence-level hashes, and local paths. File-level SHA-256 values of controlled analysis inputs are included only to identify the analysed versions; they cannot reconstruct the source records.

These restrictions reduce privacy, legal, platform, and misuse risks. Public aggregate results cannot be used to reconstruct the controlled corpus.

## Access Requests

Controlled access is not guaranteed. Any request must be considered case by case by the authorised project and institutional decision-makers. Approved access must be documented, time-limited, restricted to the minimum necessary, and handled outside GitHub. See [Controlled Audit Access](docs/CONTROLLED_AUDIT_ACCESS.md).
